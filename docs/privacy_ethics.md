# Privacy & Ethics

This project avoids PHI and relies on public or synthetic datasets.

- Data minimization: ingest only variables required for hypotheses/tests.
- Retention: keep only processed aggregates needed for results.
- Access: local development only.
- Reproducibility: store dataset links, hashes, and row counts — not the data itself.

IRB note: academic use of public/synthetic data; not human subjects research. If operational data is ever included, revisit HIPAA and org policy.
