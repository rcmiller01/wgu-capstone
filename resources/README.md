# Resources Directory

This directory contains external tools and dependencies.

## Synthea JAR

Download Synthea with dependencies:

```bash
cd resources
curl -L -O https://github.com/synthetichealth/synthea/releases/latest/download/synthea-with-dependencies.jar
```

Or manually download from:
https://github.com/synthetichealth/synthea/releases/latest

**Expected file**: `synthea-with-dependencies.jar` (~50-70 MB)

---

**Note**: This file is excluded from Git due to size. Download locally before running data acquisition.
